  1. NOTE #032026.10.10约 1 分钟

    贴边一条内存柱，比再开一个任务管理器有用

    想看的只有内存还剩多少、网现在走得快不快。窗口好做，难的是关掉再打开还是同一个，以及托盘图标上那条不该出现的白线。

  2. NOTE #022026.09.20约 1 分钟

    给 Agent 写文件之前，先挡住工作区里的 .env

    模型能改文件、跑命令之后，怕的是它被眼前这个仓库带着走。工作区里的 .env 不能改写已经配好的 API 地址。
